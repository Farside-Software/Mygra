## Description (1547/4000)

片頭痛の記録を、わかりやすく、プライベートに残しましょう。

Mygraは、静かで安心して使える片頭痛の記録アプリです。発作を数秒で記録し、睡眠や天気も一緒に残せます。データはお使いのデバイスと自分のiCloudだけに保存され、ヘルスケアとも連携します。

無料でダウンロード、基本の記録はずっと無料
• 開始・終了時刻、痛みとストレス（0〜10）、トリガー（用意されたリストまたは自分で追加）、薬、食べ物、メモを記録。
• 発作の最中はロック画面とDynamic Islandのライブアクティビティで経過を確認。アプリを開かずに痛みを−／＋で調整したり、終了したりできます。
• ヘルスケアと天気を自動で添付。睡眠、飲んだもの、外の状況が記録に残ります。
• 今月と先月の比較、30日間のカレンダーストリップ、よく記録するトリガーと薬、片頭痛が始まりやすい時間帯を表示するダッシュボード。
• 強さで色分けされたカレンダー、月ごとに整理された検索できる履歴、ピン留め、タグ、フィルタ。
• 終了した片頭痛は頭痛としてヘルスケアに書き込まれます。

どこでも使えます
• iPhone、iPad、Apple Watch、Apple Vision Pro に対応。
• iPhone Duo向けに最適化：展開時は詳細ページを2カラムで、カレンダーと一日のリストを並べて、設定を分割ビューで表示。
• Apple Watchアプリとコンプリケーション、最後の片頭痛からの日数を表示するホーム画面ウィジェット。
• SiriとショートカットApp：最後の片頭痛や今月の回数を聞いたり、薬やトリガーを記録したり、声で片頭痛を開始・終了できます。水分とカフェインのアクションも。

MYGRA PLUS
必要になったときに、分析の機能を追加できます。
• 片頭痛アシスタント：デバイス上のApple Intelligenceと会話できます。実際の記録を参照し、回答を順次表示します。内容がデバイスの外に出ることはありません。
• Quick Bitsとトリガー分析：トリガー、睡眠、水分、天気にわたる傾向。
• 天気の通知：気圧や天気が大きく変わったときにお知らせ。
• Cycle Insights：発作と月経周期の重なりを確認。
• 医師と共有しやすいPDFレポートと、全履歴のCSV書き出し。

Mygra Plusは月額$2.99、年額$14.99（7日間の無料トライアル付き）、または$29.99の買い切りです。サブスクリプションは設定からキャンセルしない限り自動更新されます。ファミリー共有に対応。2.0より前にMygraを購入された方は、Plusをずっと無料でお使いいただけます。

プライバシー重視の設計
データはデバイスと個人のiCloudにのみ保存されます。アカウント、サーバ、トラッキングはありません。AIによる分析がデバイスの外に出ることはありません。

慢性的な片頭痛でも、たまの頭痛でも、Mygraは状態をわかりやすく記録し、医療チームとの相談に役立てられるようお手伝いします。

Mygraは記録用のジャーナルであり、医療機器ではありません。分析は情報提供のみを目的としており、医学的なアドバイスではありません。片頭痛アシスタントにはApple Intelligenceが必要です。英語、スペイン語、フランス語（カナダ）、日本語に対応。
